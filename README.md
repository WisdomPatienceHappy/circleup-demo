# CircleUp interactive concept demo

A sample directory and gathering experience: communities, events, practitioners, forum, learning, news, lounge, meeting preview and member profile.

Published for design review. All listed people, communities and events are fictional examples. Meetings simulate controls; real audio/video and account authentication are not connected.

On GitHub Pages, changes stay in the current browser. Use Your data & backup from the profile or About this demo to download and restore a portable JSON backup. No local database is included in this repository.
